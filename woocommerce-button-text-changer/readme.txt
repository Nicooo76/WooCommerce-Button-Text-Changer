Ändert den Text des WooCommerce "In den Warenkorb"- und Affiliate-Buttons.

== Description ==

Mit diesem Plugin kannst du die Button-Texte von WooCommerce anpassen:

* **„In den Warenkorb“-Button** – für normale Produkte (Einzelprodukt- und Shop-Seiten)
* **Affiliate-/Externe-Produkt-Button** – für externe/Affiliate-Produkte (z. B. „Jetzt kaufen“)

Einstellungen findest du unter **Einstellungen → WooCommerce Button Text**.

== Installation ==

1. WooCommerce muss installiert und aktiviert sein.
2. Plugin in den Ordner `wp-content/plugins/woocommerce-button-text-changer` hochladen oder dort entpacken.
3. Plugin unter „Plugins“ aktivieren.
4. Unter **Einstellungen → WooCommerce Button Text** die gewünschten Texte eintragen.
